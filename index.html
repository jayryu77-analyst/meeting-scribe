일정 관리

한 줄에 한 미팅. 탭으로 구분: 날짜 · 시작 · 종료 · 기관 · 담당자 · 전화 · 장소 · 브로커. 기존 메모는 날짜·시작시간이 같으면 유지됩니다.

설정

PC 마이크 (맥·윈도우 크롬·엣지)

증폭과 마이크 선택은 PC 크롬(133 이상)에서 적용됩니다. 지원하지 않는 브라우저에서는 기본 마이크로 받아씁니다. 줌·팀즈 소리는 미팅 카드의 '컴퓨터 소리 포함'을 켜고 받아쓰기를 시작하세요.

기기 간 동기화 (휴대폰 ↔ PC)

일정·메모·녹취·요약이 이 비밀번호로 암호화되어 저장소에 저장됩니다. 비밀번호를 잊으면 저장소 데이터는 복구할 수 없습니다(각 기기에 남은 데이터는 그대로). 휴대폰과 PC에 같은 세 가지를 넣으면 앱을 열 때와 수정 후 몇 초 뒤 자동으로 맞춰집니다.

요약 방식

휴대폰 방식: 갤럭시는 삼성 녹음 앱에서 녹음 → 텍스트 변환 → 요약 → 공유 → 미팅노트를 고르면 요약 칸에 바로 들어갑니다. 아이폰은 요약 칸의 글을 선택하고 '글쓰기 도구 → 요약'을 누릅니다. 어느 방식이든 녹음·요약은 휴대폰 안에서 처리되고 외부 AI로 보내지 않습니다(Claude 방식 제외).

API 키 없이 쓰는 방법입니다. "정리 페이지로 보내기"를 누르면 기록이 복사되고 이 주소가 열립니다. 각자 자기 Claude 계정으로 정리되며, 결과도 각자 계정에만 저장됩니다.

키는 이 기기 브라우저에만 저장됩니다. 키가 없으면 "AI 요약"·"랩업 만들기"를 누를 때 기록이 복사되고 정리 페이지가 열립니다. 그 페이지에서 정리한 뒤 '앱으로 가져갈 결과 복사' → 이 앱의 '정리 결과 가져오기'를 누르면 요약이 각 미팅에 들어갑니다. 키를 넣으면 앱 안에서 바로 정리되며, 이때 녹취·메모가 Anthropic API로 전송됩니다.

모든 일정·메모·녹취는 이 기기 브라우저에만 저장됩니다. 음성 파일은 저장하지 않습니다. 기기를 바꾸거나 브라우저 데이터를 지우기 전에 백업 파일을 저장하세요.작성자 · 미래에셋증권 AI리서치센터 류제현
