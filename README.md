# 미팅 받아쓰기

휴대폰 브라우저에서 미팅 내용을 실시간으로 텍스트로 받아쓰는 웹앱입니다.

- 음성 파일은 저장하지 않고, 받아쓴 텍스트만 휴대폰(브라우저 저장소)에 남습니다.
- 갤럭시: 크롬 / 아이폰: 사파리 → "홈 화면에 추가"로 앱처럼 사용
- 주소: https://jayryu77-analyst.github.io/meeting-scribe/

## 파일
| 파일 | 역할 |
|---|---|
| index.html | 앱 화면과 동작 전체 |
| manifest.webmanifest | 홈 화면 앱 설정(이름·아이콘) |
| sw.js | 앱 화면 캐시(빠른 실행) |
| icon-192.png, icon-512.png | 앱 아이콘 |
